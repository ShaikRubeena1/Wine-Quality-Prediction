# Wine Quality Prediction using Machine Learning

## Project Overview

This project predicts the quality of wine based on its physicochemical properties using Machine Learning techniques.

The objective is to help wine manufacturers improve quality control and understand which factors most influence wine quality.


## Business Problem

Wine producers need reliable methods to evaluate wine quality before it reaches customers.

Traditional quality assessment relies heavily on expert tasting, which can be subjective and time-consuming.

This project uses machine learning to predict wine quality based on measurable chemical properties.


## Dataset Information

The dataset contains the following attributes:

- Fixed Acidity
- Volatile Acidity
- Citric Acid
- Residual Sugar
- Chlorides
- Free Sulfur Dioxide
- Total Sulfur Dioxide
- Density
- pH
- Sulphates
- Alcohol
- Quality (Target Variable)

## Key Insights

- Alcohol content has a strong positive impact on wine quality.
- Volatile acidity negatively affects quality.
- Sulphates contribute positively to higher-quality wines.
- Chemical composition can effectively predict wine quality.
